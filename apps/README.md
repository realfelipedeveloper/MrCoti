# Apps

Aplicações executáveis do Mr Coti.

- `api/`: backend NestJS futuro, monólito modular da fatia dev/local.
- `web/`: frontend Next.js futuro, interface local da jornada principal.

As aplicações devem respeitar a Spec 002, usar apenas dados sintéticos e rodar em
ambiente dev/local via Docker Desktop/local Docker.
