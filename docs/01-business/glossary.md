# Glossário ubíquo

| Termo | Definição |
| --- | --- |
| Tenant | fronteira contratual, comercial e de isolamento de dados do cliente SaaS |
| Empresa | pessoa/organização operacional pertencente a um tenant |
| Unidade | local ou operação vinculada a uma empresa |
| Vínculo | associação de um usuário a tenant/empresa/unidade e seus papéis |
| Plano | oferta comercial versionada com capacidades e limites padrão |
| Assinatura | adesão de um tenant a uma versão de plano durante um ciclo |
| Entitlement | concessão efetiva de uma capacidade ao tenant |
| Feature flag | controle operacional de disponibilidade/rollout, não substitui permissão |
| Limite | cota mensurável por período ou quantidade corrente |
| Mesa | recurso físico/lógico de atendimento de uma unidade |
| Comanda | agregado que organiza consumo antes do fechamento |
| Pedido | solicitação imutável/versionada de itens dentro de uma comanda |
| Conta | composição financeira preparada para divisão e pagamento |
| Outbox | registro transacional de eventos a publicar de forma assíncrona |
| Idempotência | propriedade que evita repetir o efeito de uma mesma intenção |
| Webhook | notificação HTTP assinada e entregue com retries a um endpoint cadastrado |
| Dado pessoal | informação relacionada a pessoa natural identificada/identificável conforme LGPD |
