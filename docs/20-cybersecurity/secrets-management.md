# Gestão de secrets

## MVP local

- secrets fora do repositório;
- `.env` local não versionado;
- exemplos sem segredo real;
- logs sem tokens;
- rotação documentada para credenciais de teste.

## Produção futura

- secret manager/cloud vault;
- acesso mínimo por workload;
- rotação testada;
- trilha de acesso;
- resposta a vazamento.
