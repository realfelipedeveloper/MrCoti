# Matriz de testes RBAC

Cada comando sensível deve ter:

- ator permitido;
- ator negado;
- tenant suspenso/cancelado quando aplicável;
- usuário sem membership;
- recurso de outro tenant;
- unidade fora do escopo;
- estado de recurso inválido;
- auditoria de sucesso e negação relevante.

A matriz funcional de referência é `docs/18-governance/rbac-matrix-mvp.md`.
