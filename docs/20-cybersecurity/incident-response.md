# Resposta a incidente

Fluxo mínimo:

1. detectar;
2. classificar;
3. conter;
4. preservar evidência;
5. erradicar;
6. recuperar;
7. comunicar quando aplicável;
8. aprender e criar regressão/teste.

Runbooks futuros devem cobrir credencial vazada, acesso cross-tenant, webhook
abusivo, dependência crítica vulnerável, provider fake em comportamento indevido e
exposição acidental de dado pessoal.
